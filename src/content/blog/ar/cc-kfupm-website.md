في العام الجامعي 2023–2024 انضممت إلى فريق صغير من الطلاب يبني موقعًا جديدًا لنادي الحاسب في جامعة الملك فهد للبترول والمعادن. احتاج النادي إلى شيئين معًا: واجهة عامة للطلاب، ومكتب خلفي لمن يديرونه.

## موقعان في موقع واحد

**الجانب العام** يعرّف بالنادي وفعالياته. لكل فعالية صفحة خاصة فيها الملصقات والصور والمستندات، ويُحوَّل زوار الجوال مباشرة إلى صفحة بحسابات النادي الرسمية.

**لوحة التحكم** لمشرفي النادي، وفيها ثلاثة أقسام:

- **نظرة عامة** على ما هو قادم وما تغيّر مؤخرًا،
- **الفعاليات** مرتبة حسب الفصل الدراسي والتصنيف، وكل منها إما عامة أو للأعضاء فقط، مع مرفقاتها،
- **الأعضاء** بأدوارهم (مشرف أو عضو) وإمكانية تفعيل الحسابات أو تعطيلها.

كان الدخول بحسابات مايكروسوفت الجامعية، لكن الحساب الجامعي وحده لم يكن كافيًا: في بيئة الإنتاج لا يدخل إلا الأعضاء المسجلون والمفعّلون مسبقًا في لوحة التحكم.

## التقنيات

بُني الموقع كتطبيق [T3](https://create.t3.gg/): ‏Next.js 13 وTypeScript وtRPC وPrisma مع PostgreSQL وNextAuth، مع تخزين Supabase للصور والملفات. واستخدمت الواجهة Tailwind CSS وshadcn/ui، وnext-i18next للعربية والإنجليزية.

قيمة هذه التقنيات أن الأنواع (Types) تمتد من طرف إلى طرف: يعرّف مخطط قاعدة البيانات شكل الفعالية مرة واحدة، فترثه الواجهة البرمجية والواجهة دون عميل منفصل يجب مزامنته:

```prisma
model Event {
    id          String   @id @default(cuid())
    title       String
    description String   @db.Text
    date        DateTime
    public      Boolean  @default(true)

    Organizers  User[]
    Attachments Attachment[]

    Semester   Semester @relation(fields: [semesterId], references: [id], onDelete: Cascade)
    semesterId String

    Category   EventCategory @relation(fields: [categoryId], references: [id], onDelete: Cascade)
    categoryId String

    link String @db.Text
}
```

ويحتفظ المخطط أيضًا بسجل لتحديثات النظام (إنشاء الفعاليات وتعديلها وحذفها، وإضافة الأعضاء وتغييرهم)، وهذا ما جعل بناء قسم «آخر التحديثات» في لوحة التحكم أمرًا مباشرًا.

## دوري في المشروع

تركّز عملي على واجهة لوحة التحكم وتصاميم الجوال، عبر 18 مساهمة بين نوفمبر 2023 وفبراير 2024:

- **صفحة الأعضاء**: بطاقات الأعضاء وشريط البحث.
- **الشريط الجانبي للوحة التحكم**: تنقل يتكيف مع الشاشات الصغيرة.
- **النظرة العامة**: شريط العرض السريع، ولوحة الفعاليات القادمة، وقسم آخر التحديثات.
- **صفحة رئيسية متجاوبة**: دعم الجوال لقسم الواجهة الرئيسي، وإصلاحات لمقاسات صعبة مثل الآيباد بالوضع العمودي.

مرّ كل شيء عبر طلبات دمج يراجعها الزملاء، مع فرض التنسيق بأداة Prettier في التكامل المستمر.

## ما تعلمته

- **مكتبة مكونات مشتركة تسرّع الفريق الطلابي.** مع shadcn/ui أساسًا مشتركًا، بدت لوحات التحكم الجديدة متسقة منذ البداية أيًّا كان من بناها.
- **«التجاوب» يعيش في المقاسات الوسطى.** الجوال وسطح المكتب كانا سهلين، أما الأجهزة اللوحية بالوضع العمودي فهي حيث انكسرت التخطيطات.
- **صمّم السجل لا الحالة فقط.** تسجيل التغييرات كبيانات أعطى لوحة التحكم سجل نشاط بلا تكلفة تقريبًا.
